ChocoSnap

Cara pakai
1. Ekstrak zip ini, biarkan index.html, style.css, dan script.js dalam satu folder.
2. Buka index.html di browser (perlu internet untuk font Google Fonts).
3. Agar kamera langsung berfungsi, buka lewat HTTPS atau localhost:
   - Netlify Drop: seret folder ini ke app.netlify.com/drop
   - GitHub Pages, atau jalankan "python3 -m http.server" lalu buka http://localhost:8000

Catatan
- Kode QR di strip memakai tautan yang kamu isi sendiri (album, Instagram, dll).
- Tombol "QR untuk unduh di HP" hanya ada di versi artifact Claude, tidak di paket ini.
- Pustaka QR (Kazuhiko Arase, lisensi MIT) sudah disematkan di script.js.
